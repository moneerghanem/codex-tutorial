This site is not official OpenAI documentation and is not affiliated with or endorsed by OpenAI. AI use is encouraged in the course; students remain responsible for understanding and verifying their work.

What “verified” means here

Last documentation verification: 14 October 2026. We opened supporting official pages, followed redirects, and used current documentation rather than search snippets. Installation alternatives also use OpenAI’s official repository README.

Practical local CLI checks used codex-cli 0.162.0-alpha.17.2: version and help for top-level, login and exec commands. This prerelease is the build environment’s version, not a required student version. No claim is made that every slash command was interactively tested or that installers were tested on all operating systems. Examples and transcripts are illustrative unless explicitly described as observed validation.

Account availability, model catalogs, usage limits and administrative policies vary. This site intentionally avoids fixed prices, unlimited-use promises and a frozen model list. Consult current model information and the account’s displayed access details.

Privacy and local progress

Lesson progress and walkthrough position are stored in this browser’s local storage. There is no site login, analytics integration, database, live AI grading or Codex execution. Clearing browser storage can remove progress; unavailable storage falls back to this page session. GitHub, as host, has its own request logging and privacy policies.

Update responsibly

Lesson bodies live separately from layouts. Reopen official sources when changing technical claims, record the verification date and CLI version, update the source register, regenerate the site and rerun checks. Never mark a transcript as real unless its evidence is recorded. See the repository README for the build and deployment procedure.
