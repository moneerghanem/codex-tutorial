# Counter completed

Completed comparison solution: state is nonnegative and Reset returns to zero.

Open index.html in a browser. No server or installation is required.

Optional logic check (Node.js required): node check.mjs
The starter intentionally fails until fixed. This check does not test DOM, screen readers or keyboard behavior.
