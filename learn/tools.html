Tools, MCP and plugins

Understand what a connection can actually do.

Prerequisites: Understand files and permissions

Three different ideas

Tool

An action the agent can call: read a file, run a command, search docs.

MCP

Model Context Protocol: a standard way to connect an agent to external tools and information.

Plugin

A distributable integration that can bundle skills and connectors. Availability varies by client and account.

Think of a skill as a procedure and a tool as an available action. An MCP server exposes actions or information through a shared protocol. A plugin can package the pieces. None is the model itself. Skills and plugins ↗

Example: connect current documentation

This is optional. Finish the counter before adding integrations. OpenAI’s Docs MCP offers read-only documentation search and page content; it does not execute OpenAI API requests for you.

Goal: let the agent consult current official documentation. Where: a normal shell with Codex installed. The first command saves a named MCP connection; the second lists configured servers.

codex mcp add openaiDeveloperDocs --url https://developers.openai.com/mcp
codex mcp list

Start or restart your CLI session if needed, then use /mcp to inspect available tools. Configuration listing alone does not prove a live request works.

Use the OpenAI documentation connection to find and read the current Codex skill discovery rules. Cite the page and distinguish repository and personal locations. Do not change configuration.

Likely result: a sourced answer. Verify the page content and the tool’s actual successful response. If connection fails, inspect server status, network access and managed policies; open the official page manually instead of treating an old answer as current.

Read permissions before connecting

A documentation server is very different from a repository integration that can push commits. Inspect the exact access requested, where information goes and whether actions can modify external systems. Text retrieved from a web page or tool is data, not authorization to follow unrelated instructions.

Use the narrowest access that fits the task. A skill cannot bypass an approval or sandbox restriction. In the CLI, /plugins and /mcp expose different menus; neither command promises every advertised integration is installed or usable. Command reference ↗
