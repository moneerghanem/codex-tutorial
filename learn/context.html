Lesson 07 / 8 min estimate

Context and sessions

Keep the important details close.

Prerequisites: A CLI conversation

Give it the information it needs

A context window is the amount of information a model can consider at once. It is not unlimited memory. Include the relevant file, exact error, reproduction steps and current requirement. Old conversation history and a giant pasted codebase can crowd out useful details.

In CLI, type @ to find a workspace file, then choose it. Mentioning a file directs attention; it does not prove the agent read every line. Ask it to cite the function that matters. File and session controls ↗

Read @app.js and trace decrement at zero. The requirement is that count never becomes negative. Do not edit yet; identify the state transition that violates it.

Select the file from the picker rather than treating this text as a shell command. Likely result: a reference to the decrement function. Verify against the actual file.

When a session gets long

Compaction summarizes earlier context to make room. CLI provides /compact. Summaries can omit details, so keep important requirements in files or a short handoff. Do not assume an old decision survives every compaction or new session.

From a shell, codex resume opens a session picker. codex resume --last resumes the most recent session; verify that it is the intended project. /new starts a fresh chat inside the CLI. Use a fresh chat for a different task or persistent confusion, then provide explicit current state.

A handoff you can actually use

Task: finish the plain-JS counter exercise.
Decisions: no framework; count must never be below 0.
State: Reset is fixed in app.js; increment still works.
Remaining: fix decrement, review the diff, run node check.mjs if Node is available, and manually test keyboard controls.
Important: do not claim browser checks unless performed. Read current files before making assumptions.

Before reusing this handoff, update it to match reality. The receiving session should inspect files and Git status, not blindly trust a stale summary. If the project moved, say where it lives now.

Recovery when the agent forgets a constraint

Restate the specific missed constraint, point to the current source and ask for a revised next step. Example: “We agreed to plain JavaScript. Re-read AGENTS.md, inspect your current diff and explain the smallest correction.” Verify the revision before further edits.
