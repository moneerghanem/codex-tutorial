What is Codex?

Meet the agent. Keep your judgment.

Prerequisites: Basic programming knowledge

Code suggestions can become actions

Codex is OpenAI’s coding agent: you describe a task, and it can use available tools to work on a project. A model generates responses and proposes actions. Tools let the agent read files, edit code or run a command. Access depends on the interface, environment and permissions.

In a normal code conversation, you often copy a suggested function into your editor yourself. An agent working inside a workspace—the project folder it has been given—can inspect the actual function and change that file. The difference matters: the result is a real edit that you must review.

Your role: set direction and judge the evidence.

You do not have to know the fix in advance. You do need to say what should happen and check whether it does.

A useful working loop

  1. 01 UnderstandDefine the goal and constraints.
  2. 02 InspectRead relevant code and errors.
  3. 03 ActEdit a file or run a tool.
  4. 04 CheckCompare observed results with the goal.
  5. 05 ContinueReport evidence or correct the result.

This diagram is a conceptual workflow, not a description of hidden internal reasoning. In practice, the agent may repeat steps, ask for clarification or stop at an access restriction.

IDE extensionInside a supported code editor, with editor context.Use the same task prompts, but its own command menu.
DesktopA graphical app with project and chat controls.Select the correct project and inspect its review panel.
CloudA configured remote environment.Local files and dependencies are not automatically there. Availability and setup differ.

Do not paste CLI slash commands into ordinary ChatGPT web chat and expect CLI behavior. Sign-in options and workspace access can also differ; cloud requires ChatGPT sign-in. Authentication source ↗

What can go wrong?

Codex can misread your request, miss a file, produce incorrect code or report a check it did not actually run. A sandbox limits which files, commands or network actions tools can access. An approval is permission to attempt an action, not proof that the action is correct.

For the counter project, “make the number smaller” is incomplete. Does zero become negative? Does Reset work after five clicks? Turn those questions into concrete checks.

Quick self-check: who decides what “done” means?

You and the project requirements do. Codex’s final message is evidence to examine, not the definition of success.
