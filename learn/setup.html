Get it running

The right terminal, the right folder, your first session.

Prerequisites: A computer, internet access and eligible Codex access

Before you install

You need an internet connection, a browser, a terminal and access to Codex through an eligible account or API billing setup. A terminal is the window where you type shell commands. The shell (PowerShell, Bash or Zsh, for example) interprets them. The practice webpage itself needs only a browser.

Use your own computer or your course’s approved environment. Managed computers may restrict installation or sign-in. Do not change university security settings to force an installation.

Install for your operating system

Choose the environment where your project will live. These are alternatives; you do not need all of them.

Native Windows · PowerShell

Open Windows Terminal and select PowerShell. This route uses the official npm package, so first install a current supported Node.js release from Node.js if it is missing. Node supplies npm, its package installer. Check that both commands print version numbers:

node --version
npm --version

The next command installs the Codex command globally for your user/environment. It downloads software; use the exact official package name.

npm install -g @openai/codex
codex --version

Expected: a Codex version, not “command not found.” If PowerShell blocks npm.ps1, try npm.cmd install -g @openai/codex; do not weaken execution policy as a first fix. Native Codex uses the Windows sandbox; follow any setup prompt and your device’s policy. Official package ↗ · Windows sandbox ↗

Windows alternative: WSL2

WSL is Windows Subsystem for Linux. Choose it when your course uses Linux tools. Install WSL using your institution’s procedure or the official WSL guide. In an existing WSL2 Ubuntu terminal, use the Linux installer below. Keep the project in ~/code/counter-starter inside Linux; installing Codex in PowerShell does not install it inside WSL. Current Codex does not support WSL1. Windows-mounted folders under /mnt/c can be slower. Open Linux files through Explorer’s WSL location when needed.

curl -fsSL https://chatgpt.com/codex/install.sh | sh
codex --version

After extracting the download, move the counter folder into your Linux home directory before proceeding.

macOS · Terminal

Open the Terminal app (Zsh is common). The official standalone installer downloads and runs the installation script. No Node installation is required for this route. Read the official installer instructions before running it:

curl -fsSL https://chatgpt.com/codex/install.sh | sh
codex --version

Expected: a Codex version number. Open a new Terminal window if the command is not found after installation. Keep the counter folder somewhere you can find, such as Downloads.

Linux · terminal / Bash

Open your distribution’s terminal. The official standalone route needs curl and a shell; if curl is missing, use your distribution’s supported package instructions. This route does not require npm.

curl -fsSL https://chatgpt.com/codex/install.sh | sh
codex --version

Expected: a Codex version number. Reopen the terminal if its PATH—the list of locations searched for programs—has not refreshed. Official setup ↗

Open the actual project folder

Download counter-starter.zip, then extract it. In a terminal, cd changes your current directory. Replace the example path with the extracted folder on your computer; keep quotes around paths containing spaces.

cd "$HOME\Downloads\counter-starter"
Get-Location
Get-ChildItem
cd ~/Downloads/counter-starter
pwd
ls

Linux/WSL users: if you put it in ~/code, use cd ~/code/counter-starter instead. Expected: the listing includes index.html, app.js and style.css. If it only shows another folder called counter-starter, enter that folder. Do not continue from Downloads itself or your entire home folder.

Now start the agent in that folder:

codex

Sign in and check your session

Choose ChatGPT sign-in when offered and complete the browser flow with your own account. An API key is an alternative, not a universal prerequisite. ChatGPT access uses your account’s entitlement and workspace controls; API-key access uses usage-based API billing and API organization settings. A ChatGPT subscription does not automatically fund API usage. Check current eligibility and pricing rather than assuming free or unlimited access. Official authentication options ↗

After sign-in, type this inside Codex, not at the shell:

/status

Check the displayed directory and permissions. Start cautiously, particularly for an unfamiliar repository. To inspect sign-in from a separate shell, use codex login status. Never paste an API key into a prompt, screenshot, repository or class submission.

Something does not match these instructions

Read codex --help in the shell and type / inside Codex to inspect your version’s menu. Use the troubleshooting navigator for command discovery, authentication and sandbox failures.

Prefer an editor?

IDE alternative: install the official Codex extension using the supported editor instructions, open the counter folder and sign in. Use the natural-language prompts from this guide in its composer. Its slash commands and keyboard bindings are separate from the CLI reference. For desktop, select the folder in the project picker. For cloud, configure a remote environment first; opening a local browser tab does not upload your project.
