Glossary

The words, without the mystery.

Short definitions you can use while learning.

26 terms

Agent
A system that can use tools to pursue a task, rather than only return a code suggestion.
CLI
Command-line interface: a program you interact with by typing in a terminal.
Terminal
The window that hosts your shell or interactive CLI.
Shell
The program that interprets system commands, such as PowerShell, Bash or Zsh.
Workspace
The folder or environment selected for project work; access may be constrained.
Repository
A project tracked by a version-control system such as Git.
Commit
A recorded Git snapshot with a message and author.
Diff
A comparison showing added and removed content between versions.
Context
The instructions, files, tool results and conversation available for the task.
Context window
The finite amount of information a model can consider in one request.
Compaction
Summarizing earlier context to make room; details may be omitted.
Sandbox
Restrictions on tool access, such as filesystem writes or network operations.
Permission
Authorization to attempt an action; not proof the action is correct.
Dependency
A program or library required by another project.
Runtime
Software that executes a language, such as Node.js for JavaScript outside the browser.
PATH
The list of directories a shell searches to find executable programs.
IDE
Integrated development environment: a code editor with development tools.
WSL
Windows Subsystem for Linux; a Linux environment on Windows.
MCP
Model Context Protocol, a standard for connecting agent tools and information.
Skill
Reusable workflow guidance in a SKILL.md package.
Plugin
An installable integration that may bundle skills and connectors.
Worktree
A separate checkout of a Git repository with its own working files.
Hook
An action configured to run at a lifecycle event.
CI
Continuous integration: automated jobs that check changes.
Verification
Comparing observed results with explicit requirements.
Refactoring
Changing code structure while preserving intended behavior.
