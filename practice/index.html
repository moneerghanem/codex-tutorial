Seven progressive exercises

3. Protect zero

At 0, repeated minus clicks must stay 0. Also check 1 → minus → 0.

4. Improve accessibility

Use native buttons; supply clear names; preserve visible keyboard focus. Tab, Enter and Space must work. Ask what was actually browser-tested.

The agent needs actual event handlers and button markup. Reading files is evidence gathering, not proof of correctness.

Changed: Reset handler in app.js

A focused fix sets count to zero, then calls render. Check that no styling or unrelated file changed.

Ran: node check.mjs
