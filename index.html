Before you begin

What do I need?

  • Basic HTML/JavaScript familiarity.
  • A computer, terminal, browser and internet.
  • Eligible Codex access; ChatGPT sign-in may be enough.
  • Willingness to inspect code and try the result yourself.

No database, backend or paid API key is required for the practice webpage. Codex account access and billing are separate.
